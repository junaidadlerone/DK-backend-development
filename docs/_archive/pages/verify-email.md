# Verify Email

**URL**: /verify-email

## Overview
Enter the 8-digit code sent to your email during signup.

## Form
- 8 individual single-digit input boxes
- Verify Account button (enabled once all 8 digits are filled)

## Actions
- Verify Account: submit the code
- Resend Code: request a new code (available 60 seconds after last send)

## After Verification
Once verified, you are automatically logged in and redirected to /onboarding to set up your organization.
