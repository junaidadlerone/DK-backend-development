# Sign Up

**URL**: /signup

## Overview
Create a new DoorKnocker account.

## Form Fields
- text: Full name (e.g. "Jane Smith")
- email: Email address
- password: Password (min 8 characters, must include uppercase, lowercase, number, and special character like !@#$%^&*)

## Actions
- Sign Up (button)
- Or continue with Google (OAuth)
- Already have an account? Sign in today (link to /login)

## After Signup
After clicking Sign Up, an 8-digit verification code is sent to your email.
You are redirected to /verify-email to enter that code.
