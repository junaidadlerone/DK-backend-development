## Template Editor

### Panels
- **Left**: Design tools — add text, images, shapes
- **Center**: Live postcard canvas (front + back)
- **Right**: Element properties (font, size, color, position)

### Design Elements
- Text: headlines, body copy, contact info, calls to action
- Images: upload or choose from Unsplash/Pexels
- Return address (required — printed on back)
- QR Code (optional, links to a URL for campaign response tracking)

### Tips
- Save frequently
- Unsaved changes are lost if you navigate away
- Templates must be saved before use in campaigns
