# Onboarding

**URL Pattern**: /onboarding/step-N

## Steps

### Step 1: Workspace Type
Choose **Business** (standard) or **Agency** (multi-client). This cannot be changed later.

### Step 2: Business Details
- Business name
- Industry (dropdown)
- Business contact email
- Phone number
- Website URL

### Step 3: Address Details
- Country (dropdown)
- Street address
- City
- State (dropdown, loads after country is selected)
- ZIP / postal code

### Step 4: Branding
- Primary color (hex e.g. #E17019)
- Secondary color
- Accent color
- Heading font (dropdown)

### Step 5: Invite Team (optional)
Invite team members by email during setup. Can be skipped and done later from /team.

## Notes
- Onboarding is required before accessing any features
- If you leave onboarding partway, you are returned to where you left off
- Agency accounts unlock /agency/overview instead of /dashboard after completion
