# Templates Overview

A template is a saved postcard design. Every campaign must use a template — it defines what your postcard looks like when it's printed and mailed.

## Front and Back

Postcard templates always include both a **front** and a **back**. You cannot have one without the other — they are created and saved as a paired bundle.

- **Front**: your main design space — headline, offer, photos, brand colors
- **Back**: includes the return address (required), recipient address block (auto-filled), and any additional messaging or design you want to add

## Template Library

**Templates** in the sidebar takes you to your organization's template library.

Each template card shows:
- Template name
- Postcard size (4×6, 6×9, or 6×11 inches)
- Front design preview
- Last modified date
- Status (Active, Draft, or Inactive)

## Template Status

| Status | Meaning |
|---|---|
| **Draft** | Work in progress — template is being designed |
| **Active** | Published and available to select in campaign creation |
| **Inactive** | Hidden from campaign creation but still accessible in the library |

## Actions You Can Take

- **Create**: start a new template from scratch
- **Edit**: open the template editor to modify an existing template
- **Duplicate**: create a copy of the template as a new Draft
- **Delete**: permanently remove a template (only if it is not used by any active campaign)
- **Use in campaign**: go directly to campaign creation with this template pre-selected

## Postcard Sizes

DoorKnocker supports three postcard sizes:

| Size | Best For |
|---|---|
| 4×6 inches | Simple, cost-effective mailings |
| 6×9 inches | More design space, most popular size |
| 6×11 inches | Maximum impact, best for complex designs or multiple offers |

**The size is set at template creation and cannot be changed afterward.** If you need a different size, duplicate the template and start a new one at the right size.

## Agency Shared Templates

If you're using an agency workspace, the agency admin can create templates at the agency level and share them with specific client organizations. Clients can use shared templates in their campaigns but cannot edit them. See the Agency Templates guide for details.
