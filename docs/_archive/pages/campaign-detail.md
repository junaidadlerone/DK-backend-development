# Campaign Detail Page

**URL**: /campaigns/{campaign-id}

## Sections
- Header: name, status badge, action buttons (Edit, Send, Archive, Duplicate)
- Stats: total postcards, verified count, estimated cost
- Interactive map: zone center + address markers (green=verified, red=unverified)
- Address list table with per-address verification status
- Postcard preview (front and back)
- Send history log

## Actions
- **Edit**: Change name, template, or zone
- **Send**: Dispatch postcards (confirmation + cost shown first)
- **Duplicate**: Copy with new name
- **Archive**: Remove from active list
