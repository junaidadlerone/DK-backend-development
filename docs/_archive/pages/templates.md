## Templates
Postcard design library for your organization.
Each template: name, postcard size, front design preview, last modified date.

## Actions
- Create Template: open the design editor
- Edit: modify an existing template
- Duplicate: copy with a new name
- Delete: permanently remove
- Use in campaign: selected during campaign creation
